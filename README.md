# Plety — استودیوی علیرضا فروغی

سایت دوزبانهٔ طراحی و توسعهٔ وب، تولید تصویر و ویدیو با هوش مصنوعی. فارسی (راست‌چین) پیش‌فرض است؛ برای انگلیسی از سوییچ زبان یا `?lang=en` استفاده کنید.

## راه‌اندازی محلی

به Node.js نسخهٔ **22.13 یا بالاتر** و npm نیاز دارید. در پوشهٔ پروژه:

```sh
npm ci
npm run setup
npm run dev
```

سایت: `http://localhost:3000` · ورود مدیر: `http://localhost:3000/login`.
`setup` یک رمز تصادفی به شما نشان می‌دهد و `.env.local` را ایجاد می‌کند. رمز را در مدیر گذرواژه ذخیره کنید؛ فایل تنظیمات را منتشر نکنید. اسکریپت فایل موجود را بازنویسی نمی‌کند.

```sh
npm run typecheck
npm run build
npm run start
```

## مسیرها و فایل‌ها

- `/` صفحهٔ اصلی، FAQ و فرم ثبت درخواست در `/#contact`
- `/about-me` معرفی علیرضا فروغی، `/services` جزئیات خدمات
- `/login` ورود، `/admin` آمار و ۱۵ درخواست آخر؛ `/dashboard` به `/admin` هدایت می‌شود
- `app/api/auth/{login,logout}/route.ts` مدیریت نشست و `app/api/inquiries/route.ts` ثبت درخواست
- `middleware.ts` محافظت مسیرها و تعیین زبان؛ `lib/auth.ts` اعتبارسنجی JWT؛ `lib/db.ts` پایگاه SQLite
- `components/` رابط‌های مشترک؛ `lib/content.ts` محتوای دو زبان؛ `app/globals.css` و `tailwind.config.js` استایل‌ها
- `public/images/` تصاویر SVG؛ `public/fonts/` فونت محلی وزیرمتن و مجوز OFL
- `FILE-TREE.txt` فهرست کامل فایل‌های تحویلی

## استقرار

این پروژه به سرور Node.js و فضای **پایدار و قابل‌نوشتن** برای SQLite نیاز دارد؛ برای خروجی استاتیک یا محیطی با فایل‌سیستم موقت مناسب نیست. برای استقرار ساده از یک نمونهٔ سرور استفاده کنید، پشت HTTPS. برای ساخت تنظیمات اولیهٔ محیط جدید، آدرس عمومی واقعی را جایگزین کنید:

```sh
npm run setup -- alireza https://plety.example.com
```

`APP_ORIGIN` باید دقیقاً مبدأ عمومی (طرح و دامنه و در صورت نیاز پورت، بدون اسلش انتهایی) باشد. `DATABASE_PATH` را به فایل روی یک دیسک پایدار اشاره دهید؛ پیش‌فرض `.data/plety.sqlite` است. از پشتیبان سازگار با SQLite استفاده کنید و مجوز دسترسی به داده‌های فرم را محدود نگه دارید. فرم درخواست به ایمیل ارسال نمی‌کند؛ پیام‌ها مستقیماً در داشبورد ثبت و نمایش داده می‌شوند.

کوکی نشست `HttpOnly` و `SameSite=Strict` است، در حالت `production` با `Secure` صادر می‌شود، و پس از دو ساعت منقضی می‌شود. خروج کوکی مرورگر را پاک می‌کند؛ تغییر `JWT_SECRET` همهٔ نشست‌های قبلی را نامعتبر می‌کند. محدودسازی نرخ SQLite بین همهٔ کاربران یک سرور مشترک است (۸ ورود و ۲۴ درخواست در ۱۰ دقیقه). برای ترافیک عمومی افزون بر این، محدودسازی در پراکسی/CDN را تنظیم کنید.

ویدیوها از URLهای CDN ارائه‌شده پخش می‌شوند و داخل بسته نیستند. در صورت عدم پخش، تصاویر جایگزین محلی نمایش داده می‌شوند. دکمهٔ حرکت و تنظیم کاهش حرکت سیستم، پخش ویدیو و حرکت نوار ابزار را کنترل می‌کنند.
